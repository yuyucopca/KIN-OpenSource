\# KIN - Unreal Engine Game Project



\## Overview



KIN is an original third-person adventure game set in Asaret, a fictional civilization inspired by Mesoamerican cultures, where mythology and reality intertwine.



The project combines interactive storytelling, exploration, puzzle-solving, combat mechanics, and comic-style narrative sequences.



\## Technologies



\- Unreal Engine 5.6.1

\- Unreal Engine Blueprints

\- Git and Git LFS

\- Blender

\- C++ (planned for future development)



\## Implemented Systems



\- Third-person character mechanics

\- Enemy behavior and combat

\- Health and damage systems

\- Character animation logic

\- Interactive puzzles

\- Mission and objective management

\- Camera transitions

\- Interactive narrative sequences

\- User interface and game menus

\- Game state management



\## Repository Scope



This repository focuses on selected gameplay systems, project configuration, and future C++ development.



Large artistic assets, maps, external plugins, and generated Unreal Engine files are excluded.



The repository is currently a partial representation of the original project and cannot be built or executed independently.
